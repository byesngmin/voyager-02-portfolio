## 기획 의도

완성된 스토리 콘텐츠를 감상하는 데서 그치지 않고, **연출이 어떤 단위로 나뉘고 데이터가 어떤 순서로 동작하는지**를 역으로 파악하는 데 목적을 두었습니다.

## 담당 범위

- 스토리 연출 구조 분석
- 연출과 진행에 필요한 데이터테이블 구조 분석
- 분석 내용을 기획 문서로 재구성

## 구조와 협업

기획 5명이 분석 범위를 나누어 검토했습니다. 화면에 보이는 대사와 연출을 구현 가능한 데이터 항목과 진행 규칙의 관점에서 다시 정리하며, 콘텐츠 의도가 시스템 구조에 어떻게 반영되는지 살폈습니다.

## 결과와 배운 점

재구성한 구조는 이후 기업협약 수집/방치형 게임의 비주얼노벨 구조를 설계할 때 활용했습니다. 기존 콘텐츠를 정확히 분해하고 문서화하는 과정이 새로운 프로젝트의 시나리오 시스템을 구체화하는 근거가 될 수 있음을 배웠습니다.
